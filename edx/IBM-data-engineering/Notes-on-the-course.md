# EdX: IBM Data Engineering

## Data Engineering Basics for Everyone

This was the first course I had ever done on EdX, and I enjoyed it. The course was a nice blend of short lecture videos interspersed with interviews of experienced data engineers to provide valuable insight. They explained the main components of a data pipeline and gave just the right amount of information for an introductory course. Coming from a background in database administration there were no big surprises, but it did give some insight into terms I had heard but never looked into. For example the difference between a data warehouse, data mart, and a data lake. There was nothing technical in this course.

## Python Basics for Data Science

This was an introductory course to Python. There was nothing new for me here, however it served as a memory jolt as I haven't used Python in a long time. I was impressed by the use of Jupyter notebooks for the lab assessments.

## Python for Data Engineering Project

This course was mostly focused on the projects, and both were fun. They required web scraping, followed by the creation of a Python function based ETL pipeline in a single document. I think that it was possible to run the notebooks on the IBM teaching platform, but I ran them locally to get used to setting up environments on my laptop.

## Relational Database Basics

The basics of entity modelling, the logical and physical models, and normalisation were the main aspects of this course. Nothing new, but it has been around eighteen years since I designed a relational database, so it was a reminder of things I had forgotten.

## SQL for Data Science

I enjoyed this course, it was fairly basic and just a refresher for me as far as the content went. What impressed me the most was the teaching environment. It's a web based IDE that can spin up instances of PostgreSQL and MySQL, both with CLI and GUI interfaces to the databases, plus Jupyter notebooks too. There were a good number of labs too.

## SQL Concepts for Data Engineers

Another course that served mostly as a refresher. I had never coded stored procedures in MySQL before, so that was new. It has been a while so I cannot remember how it compares to Oracle and PostgreSQL PL/SQL an PL/pgSQL. It introduced views, stored procedures, joins, and described the basic ACID transaction definition.

## Linux Commands and Shell Scripting

I looked forward to this module as I haven't used Bash scripting in over a decade, and when I did use it I mostly wrote simple database backup scripts triggered via CRON.

Overall it was a good course, a nice and simple introduction into GNU tools and Bash scripting. The scripting was very weird compared to say Python, but it was fun seeing how things could be achieved by piping output to different tools. 

The networking commands took me back, I remember trying to get WiFi cards working with OpenSUSE and Ubuntu back around 2006. I can't remember the last time I had to deal with networking on an install, I'm glad things have improved so much that ifconfig is just a memory.

## Relational Database Administration

This was a good high level course touching on the main points on database administration. What is left out is the gap between knowing a high level concept exists, and the amount of knowledge needed to fully comprehend the topic, such as the complexity of query optimisation or storage administration etc.

## Building ETL and Data Pipelines with Bash, Airflow, and Kafka

There were not many labs for this course, but the ones that were had were an interesting introduction to Bash scripting in Apache Airflow. Airflow is a rather cool piece of technology for orchestrating batch jobs. The introduction to Kafka was very brief and shallow.

## Data Warehousing and BI Analytics

This was an interesting course, the first to detail the Star and Snowflake schema designs, introducing fact and dimension tables. It also introduced different grouping options like cube. I feel like more time could have gone into the SQL, but at this level the course has to be shallow to cover a wider amount of information.

I was dissapointed in that the third module, that of BI analytics required signing up for a free trial of the IBM offering in this area. There are open source BI analytic dashboard solutions, and I feel it would have been better to use one of those.
